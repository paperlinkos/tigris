# Prototype: Tigris on big screens

Link: https://claude.ai/artifact/RPsAJJGCTe6ZVMYpvKA3Mt
Status: approved 2026-11-01. This is the reference for the build.

## What it can't show
- Formatting applies to a whole line. In the real editor, bold and italic apply to the selected words.
- Nothing is saved, and a reload resets the sample notes. Sync, backup and login are only simulated.
- The Cmd+N shortcut can't be relied on in a web browser, which keeps it for opening a new window. The real web version also needs another shortcut, such as Cmd+Alt+N. The Mac app can use Cmd+N.
- Logo: left out until a new one is chosen. The name "Tigris" stands in.
- Sidebar width, expanded notes and the last open note aren't remembered yet, because a reload resets the prototype.
